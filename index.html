The Foundational Trinity

The Verbs

App Intents

Defines the actions your app can perform and the parameters required to execute them (e.g., create, delete, send).

The Nouns

App Entities

Lightweight representations of your app’s data objects. Requires an identifier and a query object to allow system retrieval.

The Finite Adjectives

App Enums

Static types defining constants with special meaning (e.g., clothing sizes, calendar RSVP statuses). Backed by String and RawRepresentable.

Two Paths: Schemas and Custom Intents

App Schemas unlock native Siri reasoning. Custom App Intents still matter today for Shortcuts, Spotlight, Control Center, and chained snippet journeys.

Custom App Intents
Shortcuts · Spotlight · Control Center

Mechanism
Expose actions and entities without conforming to a system schema.
Discovery
Strong for Shortcuts, Spotlight, widgets, and Control Center — including shortcuts Siri can help create.
Use Case
Niche features, product-specific flows, and work that does not map to an Apple domain yet.
Siri Chat
Often phrase- or shortcut-triggered. Less native natural-language reasoning than schema-backed intents.

App Schemas
The preferred baseline when a domain fits

Mechanism
Conform to Apple’s pretrained vocabulary of intents, entities, and enums.
Discovery
Siri can reason about your features, ask for confirmation, and use conversational context.
Use Case
Map app actions to domains Apple already understands — Mail, Photos, Notes, Messages, and more.
Siri Chat
Unlocks natural-language resolution, on-screen awareness, and personal context.

Implementing the Semantic Bridge

Macros act as the bridge, automatically generating the required properties and protocol conformances to tie local data to global AI models.

Proprietary Code

struct MyCustomNote {
  var title: String
  var body: String
}
→

Schema Adopted

@AppEntity(schema: .notes.note)
struct MyCustomNote {
  var title: String
  var body: String
}

@AppIntent(schema: .notes.createNote)
struct CreateMyNote {
  func perform() async throws
    -> some IntentResult { … }
}

Multi-App Orchestration

Siri’s job is not only to chat — it strings entities and intents across apps to finish a task.

User “Siri, send this event to John.” Calendar open on screen — or named by title

1 · Entities

Calendar event + person

Siri identifies the on-screen event entity and the destination contact.

2 · Intent

.messages.sendMessage

If multiple apps adopt the schema, Siri can offer a choice before sending.

3 · Snippet

Confirm, then send

A confirmation snippet previews the draft. The message can fire without launching the messaging app.

What if nothing fits a schema?

The Scenario

“My app uses Visit Logs and Tags. We have complex charting actions. Nothing fits Notes or Files.”

Don’t wait for a perfect domain

Postpone only if you believe Apple must ship your exact niche schema first. You can still expose custom App Intents and Entities for Shortcuts, Spotlight, and Control Center today.

What to do now

Subset lightweight entities, design snippet journeys, and ship custom intents. When a schema eventually fits, map into it — and chain schema intents into your custom flows for more visibility.

12 / 15

Custom Intents Still Count

Out-of-domain capabilities remain first-class through Shortcuts and Spotlight — and can still surface branded snippets.

Shortcuts

Fixed, reliable triggers

Example: “Find the closest landmark in Travel Tracking.” A custom intent (no schema) can still run via an App Shortcut and open a result snippet.

Spotlight

Entities stay findable

Index lightweight entities so system search can surface your content even when Siri chat cannot natively reason about a niche domain.

Snippet chaining

Grow beyond schemas

Buttons inside snippets can trigger follow-up custom intents — favorite a landmark, buy tickets, open a detail screen — without waiting on Apple.
